Kastideo pour Windows

Une version en aperçu : elle fonctionne bien, mais vos retours restent précieux. Version actuelle : ….

Installateur Setup.exe Version portable (.zip)

Configuration requise

  • Windows 10 ou 11, 64 bits.

Installer

  1. Téléchargez Kastideo-…-windows-x64-setup.exe et lancez-le. L'installation se fait pour votre compte, sans droits administrateur.
  2. Ou, sans installation : téléchargez Kastideo-…-windows-x64.zip, décompressez-le où vous voulez et lancez Kastideo.exe.
Avertissement de Windows

L'application n'est pas encore signée : Windows affiche « Windows a protégé votre ordinateur ». Cliquez sur Informations complémentaires, puis sur Exécuter quand même. Le message ne revient pas ensuite.

Mises à jour

Kastideo consulte les nouvelles versions au démarrage puis toutes les 12 heures. Quand une version est disponible, Installer et relancer télécharge et installe la mise à jour selon votre type d'installation (installateur ou version portable).

Ce qui est propre à Windows

  • Enregistrements en MKV, avec répétition (tous les jours, du lundi au vendredi, chaque semaine).
  • MultiVue avec choix de la disposition et groupes de chaînes mémorisés.
  • ffmpeg est fourni, pour l'envoi vers un téléviseur : voir Envoyer à la télévision.
  • Option de lancement à l'ouverture de session, pratique pour les enregistrements programmés.

Kastideo for Windows

A preview version: it works well, but your feedback remains valuable. Current version: ….

Setup.exe installer Portable version (.zip)

Requirements

  • Windows 10 or 11, 64-bit.

Installing

  1. Download Kastideo-…-windows-x64-setup.exe and run it. Installation is per user, with no administrator rights.
  2. Or, with no installation: download Kastideo-…-windows-x64.zip, extract it wherever you like and run Kastideo.exe.
Windows warning

The app is not signed yet: Windows shows “Windows protected your PC”. Click More info, then Run anyway. The message does not come back afterwards.

Updates

Kastideo checks for new versions at launch and then every 12 hours. When one is available, Install and restart downloads and installs the update according to your installation type (installer or portable version).

What is specific to Windows

  • MKV recordings, with repeat (every day, Monday to Friday, every week).
  • MultiView with layout choice and saved channel groups.
  • ffmpeg is included, for casting to a TV: see Casting to a TV.
  • Option to launch at sign-in, handy for scheduled recordings.
