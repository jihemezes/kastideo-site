IPTV player for Mac, Windows, Linux and Android

One player for everything you watch

Kastideo brings your IPTV subscription, your films, your series and your personal servers into one app. Live channels start quickly, the TV guide works like a real programme guide, and you can watch what already aired. You bring your own sources, Kastideo plays them.

Fast, stable and frugal

A playback app must start without delay and keep going all evening. Kastideo is built for that, on every platform.

Fast

Channels usually start in under a second. Zapping is immediate, and the connection to the server is closed cleanly before each new channel.

Learn more

Stable

A stream health indicator shows reception quality. If a picture freezes, Kastideo automatically switches to software decoding. The playback log explains any problem.

Learn more

Frugal

No account to create with us. Your credentials stay on your device, in the system's secure store, and are sent only to your provider.

Learn more

Choose your interface

Kastideo versions

Kastideo runs on several families of devices. The Mac version is the stable one. Windows, Linux and Android versions are in preview: they work well, but user feedback still matters. iPhone, iPad and Apple TV versions are being tested through TestFlight.

Stable version

Mac

  • macOS 14 Sonoma or later, Apple processor (M1 to M4) or Intel.
  • File to download: Kastideo-X.Y.Z.dmg. Drag the app into Applications.
  • Signed and checked by Apple, updates are automatic.
Learn more Download for Mac
Preview

Windows

  • Windows 10 or 11, 64-bit.
  • Setup.exe installer (recommended, no administrator rights), or portable version as a .zip archive.
  • Not signed yet: Windows shows “Windows protected your PC”. Click More info, then Run anyway.
Learn more Download the installer
Preview

Linux

  • Zorin OS 17 or Ubuntu 22.04: .deb package (ubuntu22.04_amd64).
  • Zorin OS 18 or Ubuntu 24.04: .deb package (ubuntu24.04_amd64).
  • Raspberry Pi 4 or 5 (64-bit system): aarch64 AppImage. Other 64-bit PC: x86_64 AppImage.
  1. The .deb installs with a double-click, or with sudo apt install ./file.deb.
  2. The AppImage opens once made executable. If it does not start, install libfuse2 (libfuse2t64 on Ubuntu 24.04 and Zorin OS 18).
Learn more Choose my file
Preview

Android et Android TV

  • Phone, tablet and Android TV set (Google TV, Chromecast with Google TV, Nvidia Shield, Philips, Sony, TCL TVs).
  • arm64-v8a APK for a recent device, armeabi-v7a for an older device or 32-bit box, universal if unsure.
  • Not on Google Play: open the APK, allow the app that opens it to install, then confirm. On Android TV, the Downloader app or a USB stick is enough.
Learn more Download the APK
Testing (TestFlight)

iPhone, iPad and Apple TV

  • Native apps for iPhone and iPad (iOS 17 or later) and for Apple TV.
  • Not on the App Store yet: try them through TestFlight, by invitation. We hope for a release soon, with no date announced.
