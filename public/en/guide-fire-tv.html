Install Kastideo on Fire TV

Fire TV Stick, Fire TV Cube and Fire TV televisions run Fire OS, a system derived from Android. Kastideo is not on the Amazon Appstore: you install it from its APK file, with the free Downloader app.

Compatibility

Kastideo's Android APK declares a TV entry, so it should appear in “Your Apps & Channels”. Fire TV devices are not yet among the officially tested ones: this procedure relies on compatibility with Android, and your feedback is welcome at contact@kastideo.com. A very old model may refuse the installation.

1. Choose the right file

Take universal: it is the largest, but it works everywhere. Several Fire TV devices, even recent ones, run a 32-bit system: the arm64-v8a file may then be refused. If you prefer a lighter file, try armeabi-v7a. In Downloader, type kastideo.com/tvu (universal), kastideo.com/tv32 (armeabi-v7a) or kastideo.com/tv (arm64-v8a): these addresses always point to the latest version. The files are also on the Kastideo for Android and Android TV page.

2. Install Downloader

  1. On the Fire TV home screen, open search and type Downloader.
  2. Choose the Downloader app (orange icon) then Get or Download.

3. Allow Downloader to install apps

  1. Open Settings then My Fire TV then Developer options.
  2. If this menu does not appear: My Fire TV then About, select the device name seven times in a row, then go back.
  3. Open Install unknown apps and turn on Downloader.

This permission only concerns Downloader. You do not need to disable any other protection.

4. Download and install Kastideo

  1. Open Downloader. In the address field, type github.com/jihemezes/kastideo/releases and confirm.
  2. Find the version whose name ends with -android, expand its files and choose the universal APK.
  3. When the download is finished, select Install, then Open.
  4. Downloader then offers to delete the file: accept, it saves space.

5. Find and use Kastideo

  • Kastideo is in Your Apps & Channels. To bring it closer to the home screen: select it, press the Menu button (three lines) on the remote then choose Move.
  • The Fire TV remote works like an Android TV one: arrows move the selection, Select confirms, Back goes back. In live TV, up and down change channel. Not every remote has Channel +/− keys. See Install Kastideo on Android TV.

6. Add your source

Typing a long password with a remote is tedious. The most comfortable way: set Kastideo up on a computer, export the backup file, then import it: see Interfaces and personalisation. The Fire TV phone app also offers a keyboard to type text.

Updates

All APKs are signed with the same key: install the new version over the old one, your settings are kept. What's new is on the What's new page.

Not working?

  • “App not installed” or “not compatible”: try the universal APK. If the error persists, the device is probably too old.
  • The download is blocked: check that Downloader is allowed in step 3.
  • Kastideo is not on the home screen: open Your Apps & Channels and scroll to the end of the list.
