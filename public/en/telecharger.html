Download from a terminal or a TV

Each file has a short address that always points to the latest version (right-hand column). It is easy to type with a remote, in the Downloader app on Android TV or Fire TV, or in a terminal:

# Mac or Linux
curl -LJO https://kastideo.com/dl/mac
curl -LJO https://kastideo.com/dl/linux

# Windows (PowerShell)
Invoke-WebRequest https://kastideo.com/dl/windows -OutFile Kastideo-setup.exe

On Android TV, in Downloader, type kastideo.com/tv (arm64-v8a, the lightest), kastideo.com/tv32 (armeabi-v7a, if arm64 is refused) or kastideo.com/tvu (universal).
