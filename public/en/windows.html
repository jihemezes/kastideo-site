Kastideo for Windows

A preview version: it works well, but your feedback remains valuable. Current version: ….

Setup.exe installer Portable version (.zip)

Short addresses: kastideo.com/dl/windows (installer) and kastideo.com/dl/windows-zip (portable). In PowerShell: Invoke-WebRequest https://kastideo.com/dl/windows -OutFile Kastideo-setup.exe

Requirements

  • Windows 10 or 11, 64-bit.

Installing

  1. Download Kastideo-…-windows-x64-setup.exe and run it. Installation is per user, with no administrator rights.
  2. Or, with no installation: download Kastideo-…-windows-x64.zip, extract it wherever you like and run Kastideo.exe.
Windows warning

The app is not signed yet: Windows shows “Windows protected your PC”. Click More info, then Run anyway. The message does not come back afterwards.

Updates

Kastideo checks for new versions at launch and then every 12 hours. When one is available, Install and restart downloads and installs the update according to your installation type (installer or portable version).

What is specific to Windows

  • MKV recordings, with repeat (every day, Monday to Friday, every week).
  • MultiView with layout choice and saved channel groups.
  • ffmpeg is included, for casting to a TV: see Casting to a TV.
  • Option to launch at sign-in, handy for scheduled recordings.
