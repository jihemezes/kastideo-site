Kastideo for Linux

A preview version, in two formats depending on your system. Current version: ….

Which file to choose

Two terminal commands give the answer: lsb_release -d for the distribution and uname -m for the architecture.

.deb, Zorin OS 17 · Ubuntu 22.04ubuntu22.04_amd64 .deb, Zorin OS 18 · Ubuntu 24.04ubuntu24.04_amd64 AppImage, 64-bit PClinux-x86_64 (uname -m: x86_64) AppImage, Raspberry Pi 4 or 5linux-aarch64 (uname -m: aarch64, 64-bit system)

Installing the .deb package

Double-click the file, or open a terminal in the Downloads folder:

sudo apt install ./kastideo_X.Y.Z_ubuntu22.04_amd64.deb

Replace the name with that of the downloaded file. To cast to a TV, also install ffmpeg:

sudo apt install ffmpeg

Using the AppImage

  1. Right-click the file, Properties, Permissions, and tick Allow executing as a program. Or in a terminal: chmod +x Kastideo-…AppImage.
  2. Double-click it. ffmpeg is already included.
  3. If it does not start, install the FUSE library: sudo apt install libfuse2 (libfuse2t64 on Ubuntu 24.04 and Zorin OS 18).

Updates

Kastideo checks for new versions at launch and then every 12 hours. Install and restart adapts to your installation type: for a .deb, the new package is downloaded then installed after your approval.
