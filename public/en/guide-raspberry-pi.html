Watch IPTV on a Raspberry Pi 4 or 5

Kastideo comes as an AppImage for 64-bit ARM processors: a Raspberry Pi 4 or 5 becomes a small IPTV player for the living room. Preview version.

Requirements

  • A Raspberry Pi 4 or 5 with a 64-bit system.
  • To check the architecture, open a terminal and type uname -m: the answer must be aarch64.

1. Download the right file

Take Kastideo-…-linux-aarch64.AppImage from the Kastideo for Linux page or from Download.

2. Make it executable and launch it

  1. Right-click the file, Properties, Permissions, then tick Allow executing as a program. Or in a terminal: chmod +x Kastideo-…-linux-aarch64.AppImage.
  2. Double-click it.
  3. If it does not start, install the FUSE library: sudo apt install libfuse2 (libfuse2t64 on an Ubuntu 24.04 based system).

ffmpeg is already included in the AppImage, for casting to a TV.

3. Add your source

Open Settings (Ctrl+,), Sources, Add a source, then choose Xtream Codes or an M3U playlist. See Add an Xtream Codes subscription.

For living-room use

  • Choose the TV interface for live TV: the channel full frame, zapping with the keyboard or a USB remote.
  • Enable Launch Kastideo at sign-in so it starts with the session, which is useful for scheduled recordings.
Good to know

Performance depends on the Pi model and the stream quality. If a picture freezes, try software decoding channel by channel: see Fast, stable and frugal.
