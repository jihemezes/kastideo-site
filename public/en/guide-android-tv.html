Install Kastideo on Android TV and Google TV

Kastideo is not on Google Play: you install it from an APK file. On a TV, three simple methods, without disabling the device's security.

Supported devices

Android TV and Google TV sets, Chromecast with Google TV, Nvidia Shield, Philips, Sony and TCL TVs. A single APK works on phone and TV. This is a preview version: it works well, but your feedback remains valuable.

1. Choose the right file

  • arm64-v8a: almost all recent boxes and TVs. The right choice if unsure.
  • armeabi-v7a: older devices and some 32-bit boxes.
  • universal: all processors, but larger.

The files are on the Kastideo for Android and Android TV page, or on Download.

2. Install on the TV

A TV's browser and file manager are often missing. Pick one of these methods:

  • Downloader (free app from the TV's Play Store): type the APK download address, then allow Downloader to install apps.
  • USB stick: copy the APK onto the stick, plug it into the TV and open the file with a file manager.
  • From a phone: transfer the APK with “Send Files to TV”.

Android does not ask you to disable its protections: it asks for a permission for a single app, the one that opens the APK (Downloader, for example). If Play Protect flags an unknown developer, choose More details then Install anyway: Kastideo is not published on Google Play.

3. Using the remote

  • Arrows move the selection, OK confirms, Back goes back.
  • For live TV, the TV interface opens: up and down (or Channel +/−) change channel, digits enter a number, left opens the channel list.
  • For movies and series, the Cinema interface opens: OK pauses, left and right skip back 10 s or forward 30 s.

4. Add your source

Typing a long address with a remote is tedious. The most comfortable way: set Kastideo up on a computer, export the backup file, then import it on the TV. See Interfaces and personalisation, or Your sources.

Updates

All APKs are signed with the same key: install the new APK over the old one, your settings are kept.
