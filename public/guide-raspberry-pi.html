Regarder l'IPTV sur Raspberry Pi 4 ou 5

Kastideo existe en AppImage pour processeur ARM 64 bits : un Raspberry Pi 4 ou 5 devient un petit lecteur IPTV pour le salon. Version en aperçu.

Prérequis

  • Un Raspberry Pi 4 ou 5 avec un système 64 bits.
  • Pour vérifier l'architecture, ouvrez un terminal et tapez uname -m : la réponse doit être aarch64.

1. Télécharger le bon fichier

Prenez Kastideo-…-linux-aarch64.AppImage sur la page Kastideo pour Linux ou sur Télécharger.

2. Le rendre exécutable et le lancer

  1. Clic droit sur le fichier, Propriétés, Permissions, puis cochez Autoriser l'exécution comme un programme. Ou en terminal : chmod +x Kastideo-…-linux-aarch64.AppImage.
  2. Double-cliquez dessus.
  3. S'il ne démarre pas, installez la bibliothèque FUSE : sudo apt install libfuse2 (libfuse2t64 sur un système basé sur Ubuntu 24.04).

ffmpeg est déjà inclus dans l'AppImage, pour l'envoi vers un téléviseur.

3. Ajouter votre source

Ouvrez Réglages (Ctrl+,), Sources, Ajouter une source, puis choisissez Xtream Codes ou une playlist M3U. Voir Ajouter un abonnement Xtream Codes.

Pour un usage au salon

  • Choisissez l'interface TV pour le direct : la chaîne en plein cadre, zapping au clavier ou à la télécommande USB.
  • Activez Lancer Kastideo à l'ouverture de session pour qu'il démarre avec la session, ce qui est utile pour les enregistrements programmés.
À savoir

Les performances dépendent du modèle de Pi et de la qualité des flux. Si une image se fige, essayez le décodage logiciel chaîne par chaîne : voir Rapide, stable et sobre.
