Kastideo pour Linux

Une version en aperçu, en deux formats selon votre système. Version actuelle : ….

Quel fichier choisir

Deux commandes dans un terminal donnent la réponse : lsb_release -d pour la distribution et uname -m pour l'architecture.

.deb, Zorin OS 17 · Ubuntu 22.04ubuntu22.04_amd64Adresse courte : kastideo.com/dl/deb22 .deb, Zorin OS 18 · Ubuntu 24.04ubuntu24.04_amd64Adresse courte : kastideo.com/dl/deb AppImage, PC 64 bitslinux-x86_64 (uname -m : x86_64)Adresse courte : kastideo.com/dl/linux AppImage, Raspberry Pi 4 ou 5linux-aarch64 (uname -m : aarch64, système 64 bits)Adresse courte : kastideo.com/dl/linux-arm

Dans un terminal, par exemple : curl -LJO https://kastideo.com/dl/linux (AppImage PC 64 bits).

Installer le paquet .deb

Double-cliquez sur le fichier, ou ouvrez un terminal dans le dossier Téléchargements :

sudo apt install ./kastideo_X.Y.Z_ubuntu22.04_amd64.deb

Remplacez le nom par celui du fichier téléchargé. Pour l'envoi vers un téléviseur, installez aussi ffmpeg :

sudo apt install ffmpeg

Utiliser l'AppImage

  1. Faites un clic droit sur le fichier, Propriétés, Permissions, et cochez Autoriser l'exécution comme un programme. Ou en terminal : chmod +x Kastideo-…AppImage.
  2. Double-cliquez dessus. ffmpeg est déjà inclus.
  3. S'il ne démarre pas, installez la bibliothèque FUSE : sudo apt install libfuse2 (libfuse2t64 sur Ubuntu 24.04 et Zorin OS 18).

Mises à jour

Kastideo consulte les nouvelles versions au démarrage puis toutes les 12 heures. Installer et relancer s'adapte à votre type d'installation : pour un .deb, le nouveau paquet est téléchargé puis installé après votre accord.
