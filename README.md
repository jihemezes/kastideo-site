# kastideo-site

Site statique de Kastideo (kastideo.com).

- `public/` : les pages publiées (`index.html`, images).
- `wrangler.jsonc` : configuration Cloudflare (Workers Builds, site statique).

Branche `main` : production (kastideo.com).
Autres branches : aperçus Cloudflare, protégés par Cloudflare Access.

Le site n'a aucune étape de compilation. Les liens de téléchargement pointent vers la dernière release publiée sur github.com/jihemezes/kastideo.
